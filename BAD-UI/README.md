# Calculadora Maligna

## Descripción

Calculadora web diseñada intencionalmente con una mala experiencia de usuario (BAD UI).  
El objetivo del proyecto fue construir una aplicación funcional pero frustrante de usar, inspirada en conceptos similares a r/baduibattles.

La calculadora incluye comportamientos caóticos como:

- Números desordenados aleatoriamente
- Botones que cambian de tamaño constantemente
- Colores aleatorios en los números
- Confirmaciones innecesarias para cada acción
- Delay aleatorio al presionar "="
- Backspace que agrega números en lugar de borrarlos
- Pantalla invertida
- Resultado mostrado en rojo

Todo el proyecto está implementado en un único archivo `index.html`, sin frameworks ni herramientas de build.

## Qué funcionó

- Generación dinámica y aleatoria de botones
- Sistema de caos visual constante
- Cálculo funcional de expresiones matemáticas
- Confirmaciones molestas antes de cada acción
- Cambio aleatorio de colores y tamaños
- Resultado destacado en rojo
- Proyecto completamente autocontenido en un solo archivo HTML

---

## Qué no funcionó / Problemas encontrados

- La experiencia de usuario es deliberadamente mala y confusa
- El color rojo de los resultados no es persistente.
- El uso de `eval()` no es seguro para proyectos reales
- Los cambios constantes de tamaño pueden romper el layout visual
- Algunas animaciones pueden resultar excesivas dependiendo del navegador
- La redistribución aleatoria de botones puede dificultar muchísimo el uso
