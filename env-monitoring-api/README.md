# Environmental IoT Monitoring API

REST API contract for an IoT environmental monitoring system.

This project defines an `OpenAPI 3.1` specification for managing environmental monitoring devices and their measurements, such as temperature and humidity readings.

## Resources

### Device
Represents an IoT monitoring device.

Fields:
- id
- name
- location
- created_at
- status

### Measurement
Represents a measurement generated by a device.

Fields:
- id
- temperature
- humidity
- timestamp
- device_id

## Main Endpoints

```http
GET /devices
POST /devices
GET /devices/{deviceId}
DELETE /devices/{deviceId}

GET /devices/{deviceId}/measurements
POST /devices/{deviceId}/measurements
DELETE /devices/{deviceId}/measurements/{measurementId}
```

## Features

- OpenAPI 3.1 specification
- RESTful nested resources
- Typed schemas
- Error responses (`400`, `404`)
- Reusable parameters
- Editable YAML contract
